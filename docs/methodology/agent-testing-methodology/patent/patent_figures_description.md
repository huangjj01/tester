## 图 4：门禁校验流程图

```
┌─────────────────────────────────────────────────────────┐
│                  完成命令触发                              │
└─────────────────────┬───────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────┐
│  步骤 1：依赖校验                                        │
│  检查 depends_on 列表中所有步骤是否为 completed           │
│                                                          │
│  未满足 → 返回 "dependency not met: <dep_id>"            │
│           退出码 = 1                                     │
└─────────────────────┬───────────────────────────────────┘
                      │ 依赖满足
                      ▼
┌─────────────────────────────────────────────────────────┐
│  步骤 2：产物文件存在性检查                               │
│  检查 output 路径对应的文件是否存在                        │
│                                                          │
│  不存在 → 返回 "artifact not found"                      │
│           退出码 = 2                                     │
└─────────────────────┬───────────────────────────────────┘
                      │ 文件存在
                      ▼
┌─────────────────────────────────────────────────────────┐
│  步骤 3：内容校验（二选一）                               │
│                                                          │
│  ┌─────────────────────────────────────────────────┐    │
│  │ 若配置 required_headings：                       │    │
│  │   对每个标题：                                    │    │
│  │     - 检查标题是否存在                            │    │
│  │     - 检查标题下是否有非空正文                     │    │
│  └─────────────────────────────────────────────────┘    │
│                                                          │
│  ┌─────────────────────────────────────────────────┐    │
│  │ 若配置 required_table_columns：                   │    │
│  │   - 检查表格是否存在                              │    │
│  │   - 检查表头是否包含所有必需列                     │    │
│  │   - 检查是否有至少 1 行非占位符有效数据            │    │
│  └─────────────────────────────────────────────────┘    │
│                                                          │
│  校验失败 → 状态设为 blocked，记录 validation_errors     │
│             返回 "BLOCKED: <错误原因>"                    │
│             退出码 = 2                                   │
└─────────────────────┬───────────────────────────────────┘
                      │ 校验通过
                      ▼
┌─────────────────────────────────────────────────────────┐
│  步骤 4：状态更新                                        │
│  - 步骤状态 → completed                                 │
│  - 记录 completed_at 时间                                │
│  - 推进 current_step 到下一个 pending 步骤               │
│  - 返回 "OK: <step_id> completed"                       │
│  - 退出码 = 0                                           │
└─────────────────────────────────────────────────────────┘
```

## 绘图说明

正式提交专利时，上述文字描述需要转换为规范的专利附图，要求：

1. 使用黑白线条图，不使用彩色。
2. 图中文字使用宋体。
3. 流程图使用标准流程图符号（矩形=处理、菱形=判断、平行四边形=输入输出）。
4. 每张图标注图号。
5. 图中的标号与说明书中的描述一致。
6. 建议使用 Visio、draw.io 或 OmniGraffle 绘制。
