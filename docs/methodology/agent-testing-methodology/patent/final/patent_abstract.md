# 摘要

## 发明名称

用于 AI Agent 测试实施流程的配置化门禁控制方法、系统、介质及程序产品

## 摘要内容

本发明公开了一种用于 AI Agent 测试实施流程的配置化门禁控制方法及系统。所述方法包括：配置加载步骤，读取定义了步骤序列、依赖关系和门禁校验规则的声明式工作流配置数据；实例创建步骤，根据任务标识和目标产物类型创建运行实例，生成唯一运行标识并确定必经步骤集合；步骤推进步骤，根据依赖关系确定当前步骤并向 AI Agent 输出校验要求；门禁校验步骤，依次执行依赖校验、产物存在性校验和产物内容校验，所述内容校验包括标题存在性与非空校验以及表格有效数据校验；状态更新步骤，校验通过时标记完成并推进，校验失败时标记阻塞并记录错误；状态持久化步骤，将状态数据持久化至本地存储以支持中断恢复。所述系统包括工作流配置模块、状态管理模块、目标产物模式模块、门禁校验模块和中断恢复模块。本发明解决了 AI Agent 在测试实施中跳过关键环节、丢失执行上下文和生成不可复核结论的技术问题。
