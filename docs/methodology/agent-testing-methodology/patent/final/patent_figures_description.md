## 图 2：门禁校验步骤的详细流程图

```
┌─────────────────────────────────────────────────────────┐
│                  完成请求触发                              │
└─────────────────────┬───────────────────────────────────┘
                      ▼
              ┌───────────────┐
              │ 步骤已完成？   │──是→ 返回成功（幂等）
              └───────┬───────┘
                      │ 否
                      ▼
┌─────────────────────────────────────────────────────────┐
│  第一层：依赖校验                                        │
│  遍历 depends_on 列表，检查每个依赖步骤状态              │
│  任一未完成 → 返回错误（退出码 1）                        │
└─────────────────────┬───────────────────────────────────┘
                      │ 全部已完成
                      ▼
┌─────────────────────────────────────────────────────────┐
│  第二层：产物存在性校验                                   │
│  检查产物文件是否存在                                     │
│  不存在 → 标记阻塞，返回（退出码 2）                      │
└─────────────────────┬───────────────────────────────────┘
                      │ 存在
                      ▼
┌─────────────────────────────────────────────────────────┐
│  第三层：产物内容校验                                     │
│                                                          │
│  ┌─────────────────────┐  ┌─────────────────────────┐  │
│  │ 标题校验             │  │ 表格校验                 │  │
│  │ - 标题存在？         │  │ - 表头含必需列？         │  │
│  │ - 标题下有内容？     │  │ - 有非占位符数据行？     │  │
│  └─────────────────────┘  └─────────────────────────┘  │
│                                                          │
│  有错误 → 标记阻塞，记录错误，返回（退出码 2）            │
└─────────────────────┬───────────────────────────────────┘
                      │ 无错误
                      ▼
┌─────────────────────────────────────────────────────────┐
│  校验通过                                                │
│  标记已完成 → 记录时间 → 推进步骤指针 → 持久化            │
│  返回成功（退出码 0）                                     │
└─────────────────────────────────────────────────────────┘
```

│  └──────────────────────┬──────────────────────────────┘  │

│                          │ 反向暴露缺口                     │

该图说明本发明方法所依赖的六类工程资产及其协同关系。规则定义强制入口，工作流负责路由，技能承载步骤，模板固化结构，字典提供判断基线，执行记录保存事实。执行记录反向暴露的缺口经人工确认后回补到各类资产中，形成持续改进的闭环。门禁控制系统通过工作流配置数据引用这些资产的结构要求，实现对 AI Agent 产物的强制校验。
