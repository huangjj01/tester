## 核心创新点

本发明的核心创新在于：

1. **分层约束方法**：提出六层约束模型（任务路由层、需求与用例层、测试实施设计层、执行证据层、判断基线层、交付与沉淀层），将 AI Agent 在测试任务中的不确定性行为纳入可控的工程过程。

2. **流程门禁系统**：提出基于配置驱动的步骤依赖校验和产物结构校验机制（Test Agent Workflow Runner），将文档约束升级为可执行、可检查、可恢复的流程保护。

3. **方法与系统结合**：六层约束方法通过流程门禁系统实现强制执行，形成"方法论指导 + 系统强制"的双重保障。

## 权利要求设计策略

### 独立权利要求 1（方法）

保护"分层约束 + 流程门禁"的完整方法。上位概念写法，不限定具体实现语言或平台。

### 独立权利要求 2（系统）

保护 Runner 系统架构。写成模块化结构：工作流配置模块、状态管理模块、门禁校验模块、目标产物模式模块、中断恢复模块。

### 从属权利要求

逐层细化六层模型的具体技术特征，以及 Runner 各模块的具体实现方式。

## 专利语言规范

- 使用"所述"指代前文已定义的技术特征
- 使用"其特征在于"引出创新点
- 使用"包括以下步骤"描述方法流程
- 使用"还包括"引出从属权利要求的附加特征
- 避免使用"优选""最好""可以"等不确定表述
- 避免使用商标名、产品名（如 Cursor、Python）作为限定
- 技术效果用"能够""实现了""解决了"表述

## 注意事项

1. 权利要求书是专利的核心，决定保护范围。写得太窄容易被绕过，写得太宽容易被驳回。
2. 说明书必须充分公开技术方案，使本领域技术人员能够实施。
3. 权利要求中的每个技术特征都必须在说明书中有对应描述。
4. 案例（EXAMPLE-1001）在专利中作为"应用实施例"，证明方案可实施，但不限定保护范围。
5. 最终提交前建议找有软件/AI 方向经验的专利代理人 review。
