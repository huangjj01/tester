# 摘要

## 摘要内容

本发明公开了一种基于分层约束与流程门禁的 AI Agent 测试工程闭环方法及系统。所述方法包括：任务路由步骤，将测试请求匹配到预定义工作流；需求与用例约束步骤，对多源需求进行甄别对齐并生成覆盖清单；测试实施设计步骤，强制完成环境前置确认、工具选型和逐用例执行方案设计；执行证据采集步骤，按证据模板持久化执行事实；判断基线约束步骤，基于业务字典和三分法将测试产出分类为正常、异常和未知；交付与沉淀步骤，生成测试报告和反思候选；流程门禁强制步骤，对每个步骤产物进行结构校验和内容非空校验，校验未通过时阻止后续步骤推进。所述系统包括工作流配置模块、状态管理模块、门禁校验模块、目标产物模式模块和中断恢复模块。本发明将 AI Agent 测试行为的不确定性纳入可执行、可检查、可恢复的工程过程。
