| 篇号    | 标题                                     | 核心卖点              | 字数目标      |
| ----- | -------------------------------------- | ----------------- | --------- |

## 每篇结构模板

1. 开头 hook（1~2 句引发共鸣）
2. 高清架构图 / 方法论主视觉
3. 正文（分小节，每节 300~500 字）
4. 金句/要点总结框
5. 下篇预告

## 风格要求

- 语言：中文，技术博客风格，不用学术腔
- 避免：空泛表达、"赋能""打造""智能化"
- 强调：真实痛点、具体案例、可操作方法
- 图表：每篇至少 1 张高清主视觉图，优先使用 `diagrams/output_premium/`
- 节奏：先讲问题，再给方案，最后留悬念

## 目标读者

- 测试工程师（尤其是开始用 AI 辅助测试的）
- 研发团队 lead（关注 AI 工具落地效果）
- AI 工程化实践者（关注 Agent 约束和可控性）
