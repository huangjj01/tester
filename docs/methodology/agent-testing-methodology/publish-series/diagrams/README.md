# 系列文章配图（Mermaid 源码）

## 使用方式

1. 复制对应 `.mmd` 文件内容
2. 粘贴到 [Mermaid Live Editor](https://mermaid.live) 
3. 右侧预览 → 导出 PNG / SVG
4. 或直接在飞书文档 / Notion 中粘贴 Mermaid 代码块渲染

## 风格建议

导出时建议：
- 背景色：白色或浅灰 `#f8f9fa`
- 主题：`default` 或 `neutral`
- 宽度：适配公众号正文宽度（约 677px）
