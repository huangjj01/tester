# 论文写作计划：让 AI Agent 设计出高质量测试用例

## 论文定位

本论文聚焦"如何让 AI Agent 设计出高质量的测试用例"这一单点问题，是已完成的《从用例设计到执行报告：一种可落地的 Agent 测试工程方法论》中第二层（需求与用例层）的深度展开。

## 主论点

AI Agent 设计高质量测试用例的关键，不在于模型的生成能力本身，而在于通过结构化的多阶段约束流程——信息源甄别、跨源冲突解决、需求基线锁定、覆盖维度系统化、测试意图驱动断言、人机协作审核——将 Agent 的"快速生成"能力转化为"可信赖的测试设计"能力。

## 核心贡献（3 个）

1. 提出 Agent 用例设计的七阶段结构化约束模型
2. 定义"测试意图驱动"的断言设计方法
3. 建立领域知识渐进沉淀机制

## 写作原则

1. 从实践出发，不写空泛理论
2. 每个方法都有对应的工程资产或案例支撑
3. 不夸大 Agent 能力，不回避人类确认的必要性
4. 保持技术博客风格，不用学术腔
5. 融入个人观点，但观点必须有实践依据
