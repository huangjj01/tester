## 四、软件功能简述（200字以内）

本软件为 AI Agent 测试实施任务提供配置化的流程门禁控制。通过声明式工作流配置定义步骤序列和门禁校验规则，强制 AI Agent 按固定步骤推进测试实施任务。系统在每个步骤完成时执行依赖校验、产物存在性校验和产物内容校验（包括标题非空校验和表格有效数据校验），校验未通过时阻止流程推进。所有状态数据持久化至本地存储，支持跨会话中断恢复。支持目标产物模式，可按需裁剪必经步骤。

## 五、技术特点简述（200字以内）

本软件采用声明式 YAML 配置定义工作流结构，通过分层门禁校验机制（依赖校验、存在性校验、内容校验）约束 AI Agent 的测试实施行为。内容校验包括 Markdown 标题存在性与非空正文校验、表格列完整性校验和占位符有效数据校验。系统通过 JSON 文件持久化运行状态和步骤状态，实现不依赖对话上下文的中断恢复。目标产物模式支持按需裁剪步骤范围。幂等性设计确保重复操作不破坏已有状态。
