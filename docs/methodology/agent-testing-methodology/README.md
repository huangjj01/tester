# Agent 测试方法论知识产权成果概览

本目录包含围绕"AI Agent 测试工程方法论"产出的三类知识产权成果：**方法论文**、**发明专利**和**软件著作权**。三者从不同维度保护和阐述同一套技术体系。

---

## 一句话总结

| 成果 | 一句话 |
|------|--------|
| 方法论文 | 提出六层约束模型，说明**为什么要这样约束 Agent**以及**效果如何** |
| 发明专利 | 保护 Runner 的**技术方案**——配置化门禁控制的方法和系统 |
| 软件著作权 | 保护 Runner 的**代码实现**——`test_agent_runner.py` 这个具体程序 |

---

## 1. 方法论文

**文件**：`agent_testing_methodology_paper_final.md`

**定位**：内部技术文档，面向团队传播和外部交流。

**核心内容**：

```
问题：Agent 会写用例 ≠ 能交付测试结果
     ↓
方法：六层约束闭环
     ├── 任务路由层 → 控制入口不确定性
     ├── 需求与用例层 → 控制覆盖不确定性
     ├── 测试实施设计层 → 控制环境和工具不确定性
     ├── 执行证据层 → 控制事实和归因不确定性
     ├── 判断基线层 → 控制结论定性不确定性
     └── 交付与沉淀层 → 控制报告和经验不确定性
     ↓
工具：Test Agent Workflow Runner（门禁系统）
     ↓
验证：两个完整案例
     ├── EXAMPLE-1001 sample-client fake-clock（业务功能测试）
     └── Runner 自身 43 条用例测试（工具自举验证）
```

**读者收获**：
- 理解 Agent 测试为什么不能只靠提示词和 skill
- 掌握六层约束模型的设计逻辑和资产分工
- 了解 Runner 如何将文档约束升级为可执行门禁
- 通过真实案例看到方法论的纠偏效果和门禁拦截记录

## 2. 发明专利

**文件**：`patent/final/` 目录下四个文件

**名称**：用于 AI Agent 测试实施流程的配置化门禁控制方法、系统、介质及程序产品

**保护范围**：Runner 的技术方案（方法 + 系统），不限于 Python 实现。

**核心权利要求**（简化）：

```
方法权利要求（独立权利要求 1）：
  S1 配置加载 → 读取声明式工作流配置（步骤序列、依赖、校验规则）
  S2 实例创建 → 按目标产物类型裁剪必经步骤
  S3 步骤推进 → 按依赖关系确定当前步骤
  S4 门禁校验 → 依赖校验 + 存在性校验 + 内容校验
  S5 状态更新 → 通过则推进，失败则阻塞
  S6 状态持久化 → 支持跨会话中断恢复

系统权利要求（独立权利要求 13）：
  工作流配置模块 + 状态管理模块 + 目标产物模式模块 + 门禁校验模块 + 中断恢复模块

共 22 项权利要求（方法 12 项 + 系统 8 项 + 介质 1 项 + 程序产品 1 项）
```

**技术亮点**：
- 标题校验 + 非空正文校验（防空壳文档）
- 表格有效数据校验 + 占位符判定（防模板数据通过）
- 目标产物模式（按需裁剪步骤，简单任务不承担完整闭环成本）
- 幂等性设计（重复操作不破坏状态）
- 配置合法性校验（启动前发现配置错误）

## 三者关系

```
┌─────────────────────────────────────────────────────┐
│                  方法论文                              │
│  "为什么要约束 Agent + 怎么约束 + 效果如何"            │
│  （学术/技术层面的完整论述）                           │
└──────────────────────┬──────────────────────────────┘
                       │ 方法论中的 Runner 部分
                       ▼
┌──────────────────────────────────────────────────────┐
│              发明专利                                  │
│  保护"配置化门禁控制"的技术方案                        │
│  （方法步骤 + 系统模块，不限语言）                     │
├──────────────────────────────────────────────────────┤
│              软件著作权                                │
│  保护 test_agent_runner.py 的代码表达                  │
│  （这个具体的 Python 实现）                           │
└──────────────────────────────────────────────────────┘
```

**互补关系**：
- 专利保护的是"方法"——别人用 Java/Go/Rust 实现同样的门禁控制方法也侵权
- 软著保护的是"代码"——别人抄袭这段 Python 代码侵权
- 方法论文不是法律保护手段，而是技术传播和团队对齐的载体
