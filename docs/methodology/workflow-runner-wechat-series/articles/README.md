# articles/ 目录说明

本目录下的 .md 文件是内部工作母稿，不是公众号最终发布稿。

## 它们包含什么

- 文章定位（篇次、目标读者、核心观点）
- 事实依据表（每个结论对应的证据来源和状态）
- 正文结构（含 `[插图位]` 标注）
- 边界与待补项（已验证 / 工程判断 / 待补证据 / 不能写死的结论）
- 给设计的补充说明（封面情绪、图位优先级、传播卡片文案）

## 不应该做什么

- 不要把本目录下的文件直接粘贴到公众号编辑器
- 不要基于本目录做二次分发
- 不要把事实依据表、边界标注等协作元数据暴露给外部读者

## 应该用哪份

面向公众号发布的纯正文版本在：

```
../wechat_ready/
```

那里的 .txt 文件已去除所有内部元数据，可直接复制粘贴。
