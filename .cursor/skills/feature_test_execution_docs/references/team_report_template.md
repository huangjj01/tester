## 生成规则

- 只从测试执行记录提炼，不新增未验证结论。
- 保留关键数字、失败项、需复测项和未执行原因。
- 群里不需要逐 case 长表时，合并为场景摘要；但不要隐藏失败、阻塞和部分覆盖。
- 若本次需求新增业务能力，必须保留“已知业务能力沉淀”段落，并提示回填对应业务能力基线文档。
- 发送到团队渠道前必须给用户预览，用户确认后再发送。
