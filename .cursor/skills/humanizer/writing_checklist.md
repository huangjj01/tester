# 写作自检清单（humanizer 轻量版）

定稿任何长文前，对照下面逐条扫一遍，发现命中就当场改。这一版**不跑**「出草稿 → 自审 → 终稿」的交互流程，只做静默自检。判定标准：能不能像一个有判断力的工程师当面把这段话讲出来。

## 用哪一版

- **默认走轻量自检（本文件）**：所有文档形式的产出定稿前都必须过一遍——测试分析文档、测试用例文档、测试执行指南、测试报告、调查报告、论文、其他文章撰写，以及覆盖矩阵、迭代/需求文档、PR/commit 文案、聊天里较长的说明性正文。逐条静默自检即可。
- **必须走完整流程（`SKILL.md`）**：**需要正式对外发送的报告**，强制按 `SKILL.md` 走完整三段流程（草稿 → "哪里像 AI 生成" 自审 → 终稿）。
- **其他情况按需走 `SKILL.md`**：上面两类之外的文字润色，命中较多或要求更高时再升级到完整流程。

## 自检清单

1. **显著性拔高**：删掉"标志着……的重要里程碑""在……的大背景下""具有关键/深远意义"这类拔高句，只留事实。
2. **推广腔 / 广告腔**：删"丰富的""卓越的""令人惊叹的""坐落于……"等溢美词，换成可核实的具体信息。
3. **-ing / "……地"堆叠后缀**：去掉"……，体现了/彰显了/确保了/有助于……"这类硬接的伪深度尾巴。
4. **对仗三连（rule of three）**：不要为了显得全面硬凑三项；该两项就两项，该一项就一项。
5. **空洞权威 / 模糊归因**：删"业内普遍认为""有专家指出""多方资料显示"这类没出处的权威腔；要么给具体来源，要么不写。
6. **滥用加粗 / 标题党 / emoji**：正文不要机械加粗短语、不要 emoji 装饰、标题不要为强调而堆词。
7. **签注式 / 预告式开场**：删"让我们深入了解……""下面带你看……""话不多说"这类宣告，直接讲内容。
8. **填充与过度对冲**："为了……""由于……的事实""在此时此刻""可能或许大概也许"→ 直接说结论，该确定就确定。
9. **空泛积极结尾**：删"前景光明""未来可期""迈出了坚实的一步"这类没信息量的升华收尾。
10. **谄媚 / 客服腔**：删"好问题！""你说得完全对""希望这对你有帮助""如需我可以继续展开"这类对话残留。
11. **句式单调 / 无观点**：长短句穿插，该有判断就给判断、该标不确定就标不确定，不要通篇中性陈述像百科。
12. **中文专属 AI 腔**：删机械的"首先/其次/再次/最后""综上所述""值得注意的是""不仅……而且……"对仗、顿号三连凑数、明显机翻腔。
13. **套路化"挑战与展望"段**：删"尽管存在……挑战，但凭借……仍将……"这类公式化收尾段，要么给具体事实，要么不写。
14. **行内标题式竖列表**：`**某项：** 一句说明` 这种 bullet 少用；能用一句话顺下来就别拆成"加粗标题 + 冒号 + 复述"。
15. **权威腔套话**：删"真正的问题在于""归根结底""本质上""核心要义在于"——后面往往只是把普通结论重说一遍。
16. **碎片化标题**：标题下不要先写一句重述标题的空话再进正文，直接进正文。
17. **资料/知识截止免责**：删"由于公开资料有限……""据现有信息推测……""截至目前掌握的信息"这类免责开场，有结论就直接给，没有就标"待确认"。
18. **同义词轮换**：同一主体不要为避免重复反复换词指代（"该订单/这笔委托/此单据/该笔交易"），统一叫法更清楚。
19. **被动 / 无主语片段**："结果被自动保留""无需额外配置"这类丢主语句，补回主语用主动语态（谁保留、谁不需要）。
20. **假范围**："从……到……"凑两端，但两端不在同一尺度上时，直接列要点，别硬套范围句式。

> 命中较多、或属于需正式对外发送的报告时，升级到 `SKILL.md` 的完整流程。
